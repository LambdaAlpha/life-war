玩法说明

两阶段生命战争

01

布局 黑白轮流在己方半场或公共中线放置己方细胞；双方连续停着后进入行动。

02

行动 每回合先向空格投放一个任意颜色的细胞，然后全盘同步演化一代。

03

演化 活细胞以“同色邻居数减异色邻居数”为有效邻居；有效值为 2 或 3 时存活。

04

诞生 空格周围黑减白为 3 时诞生黑色，为 −3 时诞生白色。

05

胜负 演化后无细胞的一方落败；双方同时归零则为和棋。
